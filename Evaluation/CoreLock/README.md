# Core architecture evidence

This directory contains current Apple-only core evidence. Earlier report files and
Evaluation/Laya, RealityGate and STTBakeoff are historical comparison evidence.

- SPEECH_REMOVAL_AUDIT.md: source/import proof before old engine deletion.
- APPLE_API_RESEARCH.md: API choices and primary Apple links.
- upstream-backbone.json: immutable current Laya upstream/file inspection.
- native-actions*.json: real Debug native effects from fixed developer requests,
  not microphone speech. VERIFIED means observable native readback.
- apple-*-smoke.json: real Apple Speech on test-owned paced Samantha audio while
  MPS training ran; not natural microphone or uncontended performance.
- Later Apple fixture runs state the same source/effect boundaries explicitly.
- Model evaluation, parity and latency artifacts are copied here after completion.
- Deletion manifest is produced before removing generated artifacts.

No user dictation history, selection contents, microphone audio, account data or
personal note contents are exported into this evidence directory. Fixed test
payloads are LocalFlow Ideas, hello from LocalFlow, Norbert Wiener and public URLs.
Human-review.csv remains pending unless the user actually reviews it.

The final real native run is native-actions-plaintext-final.json; older native runs retain failures that prompted fixes. The human continuous microphone report is manual-microphone.json. LayaV2/report.json contains failed held-out quality and disabled authority; native-parity.json validates conversion only.
